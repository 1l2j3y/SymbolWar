这是本人自学Python一个月花了两周左右才敲出来的玩意儿, 可以说是处女作吧
质量不算太好, 但我感觉已经挺不错了
刚开始是蟒蛇书的外星人入侵, 但我敲着敲着还想起来我看过的一个视频, 有人为了极限压缩游戏大小, 完全用字符串来当作图片
于是我受到启发, 舍弃了用图片来当做游戏元素, 直接全部使用内置的纯代码驱动的字符渲染, 压根没有引入一点外部图片素材, 除了背景实在没办法
背景是在pixabay网站上找的, 这个网站用来找资源还是挺不错的
音频的话来源于B站up, 一只野生的hn, 我从他的一个鬼畜音效视频里面提取的音效, 这个音效真的太抽象了, 我扛不住, 我不是那种经常刷短视频的人,玩的时候这音效总是时不时害我笑一下
开发过程中遇到的最离谱的bug不是来源于代码, 而是来源于我的电脑, 刚开始用的图片无法显示, 我还以为是图片或者说代码出了问题, 结果是我的屏幕分辨率太低, 我创建的画布高度太高, 导致图片跑到屏幕外面去了, 半个图片在屏幕外, 半个图片被任务栏吃了, 我忘记了这个电脑是768P的, 而不是1080P的, 太神经了, 害得我笑了一晚上
